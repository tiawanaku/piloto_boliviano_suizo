# Segundo Cerebro — Colegio Virtual (Scrum + Obsidian)

Vault de [Obsidian](https://obsidian.md) que funciona como **segundo cerebro** y **base de conocimiento de Scrum** para construir la plataforma de un colegio **100 % virtual** (sin aulas físicas; oficinas físicas solo para información).

## Cómo abrirlo
1. Clona este repositorio.
2. En Obsidian: **Open folder as vault** → selecciona la carpeta del repositorio.
3. Abre `00-Inicio/Inicio.md`.

## Contenido
| Carpeta | Contenido |
|---|---|
| `00-Inicio` | Mapa principal, guía de uso, glosario |
| `01-Proyecto` | Visión, contexto, stakeholders, equipo, fases y roadmap, riesgos |
| `02-Scrum` | Teoría y práctica de Scrum: pilares, valores, roles, eventos, artefactos, historias, estimación, métricas |
| `03-Producto` | Backlog del producto, DoD, DoR, 8 épicas y 28 historias de usuario |
| `04-Sprints` | Sprint 0 a 3 (Fase 1: login del personal) |
| `05-Arquitectura` | Arquitectura, modelo de dominio, RBAC, flujo de autenticación, RNF, seguridad, ADRs |
| `06-Diseno-UX` | Wireframe del login, paneles por rol, accesibilidad |
| `07-Reuniones` | Registro de reuniones y eventos Scrum |
| `08-Plantillas` | Plantillas de historia, épica, sprint, daily, review, retro, ADR, reunión |
| `09-Recursos` | Referencias y marco normativo |

## Fases del producto
1. **Login del plantel administrativo y docentes** ← fase actual
2. Estructura académica y aulas virtuales
3. Asignación de cursos y materias a las aulas virtuales
4. Aplicativo de acceso para estudiantes
5. Oficina de información y mejora continua

Plugins comunitarios opcionales: **Dataview**, **Kanban**, **Templater**.
