## Términos del colegio virtual

| Término | Definición |
|---|---|
| **Colegio virtual** | Institución educativa cuyas clases y procesos académicos ocurren 100 % en línea. Ver [[Contexto del colegio virtual]]. |
| **Aula virtual** | Espacio digital que agrupa a un paralelo (grado + sección) con sus materias, docentes, estudiantes, contenidos y actividades. Ver [[EP-04 Aulas virtuales]]. |
| **Oficina de información** | Única presencia física del colegio: atiende consultas, inscripciones y orientación. No se dictan clases allí. Ver [[EP-07 Oficina de informacion]]. |
| **Plantel administrativo** | Dirección, secretaría, coordinación académica, administración, soporte TI y personal de la oficina de información. |
| **Docente** | Profesional a cargo de una o varias materias en una o varias aulas virtuales. |
| **Gestión** | Año escolar (p. ej. Gestión 2027). |
| **Nivel** | Inicial, Primaria, Secundaria. |
| **Grado / Año de escolaridad** | 1.º, 2.º, … dentro de un nivel. |
| **Paralelo** | Sección de un grado (A, B, C…). |
| **Materia / Área** | Asignatura curricular (Matemática, Lenguaje, Ciencias Naturales…). |
| **Asignación** | Relación *docente ↔ materia ↔ aula virtual ↔ gestión*. Ver [[EP-05 Asignacion de cursos y materias]]. |
| **Matrícula** | Relación *estudiante ↔ aula virtual ↔ gestión*. |
| **App de estudiantes** | Aplicativo (móvil/web) de acceso exclusivo de estudiantes. Ver [[EP-06 App de estudiantes]]. |

## Términos técnicos
| Término | Definición |
|---|---|
| **Autenticación** | Verificar *quién* es el usuario. Ver [[Flujo de autenticacion]]. |
| **Autorización** | Decidir *qué* puede hacer. Ver [[Roles y permisos RBAC]]. |
| **RBAC** | Control de acceso basado en roles. |
| **MFA / 2FA** | Autenticación multifactor (contraseña + código TOTP). |
| **TOTP** | Código temporal de 6 dígitos generado por una app autenticadora. |
| **SSO** | Inicio de sesión único con un proveedor de identidad. |
| **LMS** | *Learning Management System* (plataforma de aprendizaje). |
| **ADR** | *Architecture Decision Record*. Ver [[Plantilla ADR]]. |
