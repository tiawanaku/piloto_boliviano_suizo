# Sprint

Volver a [[Scrum MOC]] · Sprints del proyecto: [[Sprints MOC]]

El **corazón de Scrum**: eventos de duración fija (≤ 1 mes; aquí **2 semanas**) donde las ideas se convierten en valor. Un nuevo sprint empieza inmediatamente después del anterior.

## Reglas
- No se hacen cambios que pongan en peligro el [[Objetivo del sprint]].
- La calidad no disminuye.
- El [[Product Backlog]] se refina según sea necesario.
- El alcance puede aclararse y renegociarse con el [[Product Owner]] a medida que se aprende más.

## Contiene todos los eventos
[[Sprint Planning]] → [[Daily Scrum]] (diario) → [[Sprint Review]] → [[Sprint Retrospective]]

## Cancelación
Solo el **Product Owner** puede cancelar un sprint, y únicamente si el Objetivo del sprint se vuelve obsoleto (p. ej. dirección decide cambiar el sistema de autenticación completo).
