# Sprint Planning

Volver a [[Scrum MOC]] · Plantilla: [[Plantilla Sprint]]

Inicia el sprint estableciendo el trabajo a realizar. Timebox: ≤ 8 h para un sprint de un mes (aquí ≤ 4 h).

## Tres temas
1. **¿Por qué es valioso este sprint?** → el PO propone cómo aumentar el valor; el equipo define el [[Objetivo del sprint]].
2. **¿Qué se puede terminar?** → los Developers seleccionan elementos del [[Product Backlog]] (considerando capacidad y [[Metricas agiles#Velocidad|velocidad]]).
3. **¿Cómo se hará el trabajo?** → descomponer en tareas (≈ 1 día o menos).

Resultado: el [[Sprint Backlog]] = Objetivo + elementos seleccionados + plan.

## Checklist
- [ ] Backlog superior refinado y cumpliendo [[Definition of Ready]]
- [ ] Capacidad del equipo calculada (vacaciones, feriados, reuniones)
- [ ] Objetivo del sprint redactado en una frase
- [ ] Historias seleccionadas con [[Criterios de aceptacion]] claros
- [ ] Tareas iniciales identificadas
